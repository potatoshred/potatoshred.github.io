    QEMU入门（3）Virtio MMIO

    struct VirtioMMIO字段解析

    关键寄存器列表

    Offset 名称 类型 读写流程中的作用
    0x000 MagicValue R 驱动读取，确认确实是 VirtIO 设备
    0x010 DeviceFeatures R 驱动读取，了解设备支持的功能（如多队列）
    0x030 QueueSel W 驱动写入，指定后续操作针对哪一个队列
    0x050 QueueNotify W 最频繁写入，通知设备“有活干了” (Kick)
    0x060 InterruptStatus R 驱动在中断里读取，看是哪类事件（配置改变或数据处理完）
    0x064 InterruptACK W 驱动写入，告诉设备“我知道了”，清除中断位
    0x070 Status RW 驱动维护，报告驱动的初始化阶段（ACK/DRIVER/OK）

    运行时数据通知流程 Kick Flow

    发送数据（驱动 -> 设备）

    1. 内存写入： 驱动将数据放入 Virtqueue，更新 Available Ring 的索引。
    2. Kick（敲门）： 驱动执行 MMIO 写操作：
      writel(queue_index, base + VIRTIO_MMIO_QUEUE_NOTIFY)
    3. 触发异常： CPU 捕获 MMIO 写操作，触发 VM Exit。
    4. 后端处理： Hypervisor 从内存中读取 Virtqueue 的新数据进行处理。

    接收通知（设备 -> 驱动）

    1. 后端处理： Hypervisor 将处理结果放回 Used Ring。
    2. 注入中断： Hypervisor 模拟硬件中断（如 GIC 或 APIC）。
    3. 读取状态： 驱动进入中断处理程序，首先读取 MMIO 寄存器：
      status = readl(base + VIRTIO_MMIO_INTERRUPT_STATUS)
    4. 确认中断： 驱动写寄存器清除中断标志：
      writel(status, base + VIRTIO_MMIO_INTERRUPT_ACK)

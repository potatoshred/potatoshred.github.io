    属性

    属性是“键值对”，描述硬件的具体参数。

    带#的属性表示Number of，如#address-cells，#size-cells等，语法上参考C语言的#define预处理头，现代 DTS 编译时常调用C预处理器 (CPP)。

    常见的数据类型包括：

    类型 格式 示例 说明
    字符串（String） 双引号 compatible = "arm,pl011"; 普通的文本字符串
    32位整数列表（Cell） 尖括号 < > reg = <0x1000 0x2000>; 一个或多个32位无符号整数
    64位整数 尖括号 < >（两个32位cell） reg = <0x00000001 0x00000000>; 每两个cell表示64位值
    字节序列（Byte array） 方括号 [ ] local-mac-address = [00 11 22 de ad be ef]; 原始的二进制数据
    字符串列表 逗号分隔的字符串 compatible = "fsl,mpc8349-uart", "ns16550"; 表示设备的兼容性列表
    布尔值 无值（属性存在即为真） interrupt-controller; 属性键名存在即表示条件为真
    混合列表 逗号分隔不同类型数据 mixed-prop = "hello", [01 02], <0x12345678>; 可组合不同类型数据

    常用核心属性：

    • reg：定义设备使用的地址范围，格式通常为 reg = <地址1 长度1 [地址2 长度2 …]>

    • #address-cells：指定 reg中”地址”字段占用多少个32位整数（cell）。

      • #address-cells = <2>;表示地址由两个32位单元组成，即64位地址。

    • #size-cells：指定 reg中”长度”字段占用多少个32位整数（cell）。如果长度为0，则 reg中不包含长度信息（如CPU节点）。

      • #size-cells = <1>;表示长度由一个32位单元组成，即32位长度。

    例如，在根节点中设置 #address-cells = <1>; #size-cells = <1>;，那么子节点 serial@101F0000的 reg = <0x101F0000 0x1000>;就表示地址从 0x101F0000开始，长度为 0x1000字节。

    address-cells 和 size-cells 是继承属性，子节点会默认使用父节点的值。如果子节点需要覆盖父节点的值，可以显式定义自己的 address-cells 和 size-cells。

    • phandle：节点的唯一标识符，可以被其他节点引用（如 interrupt-parent）。
    • compatible：设备兼容性描述
    • status：设备状态（如okay或disabled）

    中断相关属性

    • interrupt-controller：一个空属性，声明该节点是一个中断控制器
      • #interrupt-cells：位于中断控制器节点中，声明该控制器的中断指示符（interrupt specifier）由几个cell组成（类似于 #address-cells的作用）。
      • interrupt-parent：位于设备节点中，指向一个中断控制器的句柄（phandle），表示该设备的中断线连接到哪个中断控制器。子节点通常会继承父节点的 interrupt-parent。
      • interrupts：位于设备节点中，描述中断源的具体信息（如中断号、触发方式），其格式和含义由它所连接的 interrupt-controller 的 #interrupt-cells决定。

    特殊节点

    • chosen节点：用于指定启动时的参数，如内核命令行、初始ramdisk等。
    • aliases节点：用于为设备节点创建简短的别名，方便引用。
    • memory节点：描述系统内存布局，是必需的节点。
